Astron is a fun programming language where every keyword is borrowed from the world of rockets and space exploration.

## Installation

Build from source:

```sh
cargo build --release
```

Or install the CLI directly with Cargo:

```sh
cargo install --path .
```

## CLI

```sh
astron <file.astrn>
astron <file.astrn> --launch <name>
astron --help
astron --version
```
